About the analysis & privacy

Checking local model…

WavLM + LoRA research model, trained on English podcast clips. It reviews 3-second windows and can miss or mislabel events. Repetition types are combined by the model; you can label them more specifically yourself. Blocks are particularly uncertain.

Recordings go only to the Python process on your own computer for analysis, in memory. No cloud inference or analytics. Practice sessions save only when requested; the separate personal-training queue saves recordings you explicitly add. Saved sessions are not encrypted; anyone with access to this browser profile may access them.
